# Turntopage

把翻页交给视线和手势。不需要改任何小说 App：无障碍服务向前台应用注入真实的滑动/点击，支持**空中手势**（张手左右挥、拇指食指捏合）、**眼动**、音量键、屏幕边缘热区和悬浮球。

安装包：[GitHub Releases](https://github.com/ImPrEzAll/turntopage/releases/latest)（当前 v1.4，APK 挂在 Release 附件里）

已在小米 MIX 2S（LineageOS / Android 16，1080×2160）上实测前摄、MediaPipe、无障碍注入、模式切换、新界面与横屏旋转；平板横屏布局用 1280×800dp 逻辑分辨率（sw800dp）实机验证。

## 三步开始

1. 打开 Turntopage，按屏幕上的大按钮依次开启无障碍服务和相机权限。
2. 点「空中手势」或「眼动翻页」模式卡，选中一种方式。
3. 点「开始」。之后打开任意小说 App 正常阅读即可；悬浮球可以拖动。

眼动和空中手势共用前摄，一次只能开一种。想换方式时直接点另一张模式卡，识别服务会自动重启，约 1 秒。打开 App 自己的设置页时，悬浮球和边缘热区会暂时收起，避免挡住界面或误触。翻页参数（动作方式、灵敏度、方向反转、眨眼、捏合方向等）都收在「高级设置」里，默认值可以直接用。

## 平板与横屏

- 平板横屏（sw600dp 以上）自动变成左右双栏：左侧状态与启动，右侧用法与高级设置；平板竖屏单栏限宽居中，手机上仍是原来的单栏。
- 眼动与空中手势都跟随屏幕方向：CameraX 的目标朝向会按当前旋转更新，并且每 400ms 自查一次，正横屏、反横屏、竖屏之间切换都不用重启识别服务；旋转后短暂跳过几帧并重置手势/校准，避免旧方向误触发。
- 手势左右挥手在四种屏幕方向下都按“用户自己的左右”判断（前摄画面始终按屏幕方向摆正后再镜像）。
- 阅读测试页不再锁定竖屏；正文在平板上限宽 760dp，横屏高度不足时自动缩小字号，旋转屏幕后会停留在当前页。
- 悬浮球、面板和边缘热区会在竖横屏切换时重新贴合新尺寸，面板超出屏幕时自动收回边界内。

## 五种翻页方式

| 方式 | 操作 |
| --- | --- |
| 空中手势 | 张开手掌正对前摄，向左挥 = 下一页，向右挥 = 上一页；拇指食指捏合 = 下一页（可在高级设置改为上一页） |
| 眼动 | 注视屏幕左/右边缘停留，或双击眨眼；可选转头模式 |
| 音量键 | 音量- 下一页，音量+ 上一页 |
| 边缘热区 | 点屏幕最左 / 最右 40dp 窄条 |
| 悬浮球 | 点悬浮球展开面板：◀ / ▶ / 当前识别模式开关 / 设置；可拖动位置 |

所有方式都带冷却/重新武装，避免一次动作连翻多页。

## 空中手势提示

- 手掌张开、距离前摄约 40~70cm，让整只手都在画面里，手指尽量分开。
- 挥手要在约 0.3 秒内横向移动较大幅度；每次触发后把手停住或移出画面约半秒，再挥下一次。
- 捏合是“原始拇指尖-食指尖距离连续 2 帧降到阈值以下”确认，快速捏一下也能触发；张开到足够大才重新武装。
- 设置页顶部会显示找手 / fps / 最近手势；悬浮球在手势模式会变成手掌图标，并用橙色弧显示捏合进度。
- MIX 2S 上 HandLandmarker 约 5~7fps，眼动约 14~15fps；最低可用但不算流畅，光线不足或手离得太远会明显变差。

## 眼动提示

- 启动后先看屏幕中央约半秒完成自动校准，再注视左/右边缘约 1 秒翻页。
- 快速眨两下 = 下一页（默认开启）；觉得难触发就调低高级设置里的「触发灵敏度」数值。
- 戴眼镜可用，保持前摄能看清整张脸。

## 已验证

- JVM 单元测试 6 项：左挥只翻一次、右挥只翻一次、捏合只翻一次、捏合方向可配、单帧捏合不误触、6fps 稀疏挥手仍能识别。
- 设备上用 21 点合成手部关键点跑通：左挥 → `turn dir=1 source=wave`、右挥 → `dir=-1 source=wave`、捏合 → `dir=1 source=pinch`，内置阅读页页码实际变化。
- 设备上确认手势 / 眼动引擎启动、相机取帧、用模式卡互相切换、停止识别、悬浮面板注入（`source=panel`）与内置阅读页翻页。
- 旋转链路实测：竖屏 ↔ 横屏、正横屏 ↔ 反横屏都能在 0.4 秒内更新相机目标朝向（rotationDegrees 0/180/270 均复现），期间眼动保持 14~15fps、手势保持 6~7fps；合成挥手、合成注视在横屏下仍能翻页。
- 平板横屏（1280×800dp）逐屏检查：双栏首屏、运行态、高级设置展开、使用说明展开均无裁切；手机横屏与竖屏布局回归正常；阅读页旋转后保持页码。
- 真人手部动作的最终触发手感需要在真实光线下自行验收；自动测试使用合成关键点，不经过真人前摄画面。

## 注意事项

- 开启「音量键翻页」后，音量键会被无障碍服务消费，不再调节系统音量；需要调音量时先关掉该开关。
- 识别画面只在本机 MediaPipe 中处理，不上传。持续开摄像头会发热耗电，长时间使用建议插电。
- 部分阅读 App 的翻页区域不同，可切换「点击翻页 / 滑动翻页」并调整滑动距离；方向反了打开「方向反转」。
- 本项目用 debug 签名发布为非调试包，以避开 Android 16 对调试包的 16KB 原生库提示；MediaPipe 的 `libimage_processing_util_jni.so` 仍是 4KB 段对齐，4KB 页设备（如 MIX 2S）不受影响，16KB 页设备可能存在兼容性风险。

## 构建

```bash
./.tools/gradle-8.7/bin/gradle assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk
```

环境：AGP 8.5.2 / Gradle 8.7 / JDK 17 / compileSdk 34 / minSdk 24。

## 结构

- `MainActivity`：品牌化主界面，单按钮按步骤引导，模式卡片选择，高级设置与说明折叠；平板横屏双栏、竖屏限宽居中
- `TurnAccessibilityService`：注入手势、音量键过滤、边缘热区、悬浮球；设置页打开时隐藏悬浮层，旋转后重新贴合屏幕
- `EyeTrackingService`：CameraX 前台服务，按设置加载 FaceLandmarker 或 HandLandmarker（互斥）；跟随屏幕旋转更新目标朝向
- `GazeController`：注视平滑、自动校准、停留/冷却、双击眨眼
- `HandGestureController`：21 点手部关键点 → 张手挥手 / 捏合状态机（纯 Kotlin，可单测）
- `HandLandmarkerHelper` / `FaceLandmarkerHelper`：MediaPipe 封装与取帧节流
- `ReaderActivity`：内置 7 页阅读测试页，支持拖动/点击/注入手势翻页；debug 包内可模拟眼动与手势
